1 How to use this manual

Run the blocks in order in one R session, or use inst/examples/step_by_step.R. Each stage creates the input for the next. Optional blocks show alternatives.

The workflow is: normalization → sample distances → PCA → PCA gene selection → input preparation → classification with gene resampling → classification-based selection → ACC → ICC → ICC differences → rules for each condition → rule comparison. Distances and ACC are complementary analyses: the distance matrix is not the PCA input, and ACC is not the ICC input. Both use the relevant expression matrix.

Use the bundled example to learn the functions, then replace its matrix and metadata with your own data. Adjust parameters for your experimental design.

2 Installation and data layout

Install the package once:

install.packages(c("BiocManager", "remotes", "randomForest"))
BiocManager::install(c("edgeR", "DESeq2"), ask = FALSE, update = FALSE)
remotes::install_github("SamellaSalles/MettleRNASeq", build_vignettes = FALSE)

Requires R ≥ 4.2.0. To also install the tutorial, set build_vignettes = TRUE; this requires Pandoc, included with RStudio.

expression <- read.csv("my_matrix.csv", row.names = 1, check.names = FALSE)
metadata <- read.csv("my_metadata.csv", stringsAsFactors = FALSE)
metadata <- metadata[match(rownames(expression), metadata$Sample), ]
stopifnot(!anyNA(metadata$Sample),
  identical(rownames(expression), metadata$Sample))

3 Normalize counts: normalize_count_matrix()

Purpose: filter genes and normalize raw counts. Input: nonnegative numbers, samples in rows and genes in columns. Output: a normalized data.frame, retaining identifiers for surviving samples and genes. Normalization does not convert processed expression back into raw counts.

Parameter How to choose
count_matrix Your raw-count matrix. DESeq2 requires integer counts.
method "TMM" uses edgeR normalization factors; "DESeq2" uses size factors; "scale" scales each gene without centering. These are different procedures.
min_count Minimum count per sample for the filter; default 10.
group_size Minimum number of samples reaching min_count; default 4. This counts samples, not conditions.
remove_low_variance TRUE removes zero-variance genes; it does not apply a general low-variance threshold.

To demonstrate normalization without renormalizing the MSc example, generate synthetic raw counts. Do not mix their outputs with the real example.

set.seed(123)
counts <- as.data.frame(matrix(rnbinom(8 * 60, size = 10, mu = 100), 8))
rownames(counts) <- paste0("Sample_", 1:8)
colnames(counts) <- paste0("Gene_", 1:60)
normalized_synthetic <- normalize_count_matrix(counts, method = "TMM",
  min_count = 10, group_size = 4, remove_low_variance = TRUE)
dim(normalized_synthetic)
#> [1]  8 60
attr(normalized_synthetic, "removed_genes")
#> character(0)
attr(normalized_synthetic, "removed_samples")
#> character(0)
# Continue with the already normalized example matrix; do not normalize it again.
normalized <- expression

To retain genes reaching the threshold in at least two samples, set group_size = 2. To compare methods, start each from the same raw matrix, rather than applying methods successively. If filtering removes samples, realign metadata using match(rownames(normalized), metadata$Sample). TMM returns counts adjusted by effective library sizes, without automatic log or CPM transformation. Scaling also follows the count filters and nonnegative input requirement; this is not a generic scaler for negative-valued matrices.

deseq_counts <- normalize_count_matrix(counts, method = "DESeq2")
scaled_counts <- normalize_count_matrix(counts, method = "scale")

4 Compare samples: compute_distance_matrix()

Purpose: inspect sample similarities and display a heatmap. Input: normalized. Output: a square sample-by-sample matrix. This stage does not automatically remove samples.

Parameter How to choose
count_matrix Expression matrix with samples in rows.
use_correlation FALSE computes a distance; TRUE computes 1 - correlation between samples.
method For distances: "euclidean", "manhattan", "canberra" or "minkowski".
correlation_method For correlations: "spearman", "pearson" or "kendall".
plot_heatmap TRUE displays the heatmap; FALSE only computes the matrix.
cluster_rows, cluster_cols Enable clustering in the heatmap.
clustering_method A clustering method, such as "complete" or "average".
display_numbers, number_color Show cell values and choose their color.
color_palette, breaks Colors and number of divisions in the palette.
main_title Heatmap title; NULL uses an automatic title. 
distances <- compute_distance_matrix(normalized,
  use_correlation = TRUE, correlation_method = "spearman",
  plot_heatmap = TRUE, display_numbers = TRUE,
  main_title = "Sample distance: 1 - Spearman")

round(distances[1:4, 1:4], 3)
#>       F1B   F2B   F3B   F4B
#> F1B 0.000 0.051 0.146 0.083
#> F2B 0.051 0.000 0.209 0.037
#> F3B 0.146 0.209 0.000 0.185
#> F4B 0.083 0.037 0.185 0.000

For Euclidean comparison of expression magnitudes, use use_correlation = FALSE, method = "euclidean". The matrix is returned whether or not you request a plot. Different metrics respond to different aspects of the data and can produce different sample groupings.

6 Select genes by PCA: feature_selection_pca()

Purpose: select genes by absolute PCA loadings. Input: pca$pca_result and its matching matrix. Output: gene identifiers and a reduced matrix. A gene selected in several components appears once; two PCs × twelve genes need not yield 24 distinct genes.

Parameter How to choose
pca_result A prcomp object, here pca$pca_result.
count_matrix Matrix corresponding to the PCA, with matching gene IDs.
num_pcs Number of components to consider.
num_genes_per_pc Number of genes selected from each component.
select_worst FALSE selects largest absolute loadings; TRUE, smallest. This is not a biological ranking of good/bad genes.
use_last_pcs FALSE uses the first PCs; TRUE, the last PCs. 
pca_selection <- feature_selection_pca(pca$pca_result, normalized,
  num_pcs = 2, num_genes_per_pc = 12,
  select_worst = FALSE, use_last_pcs = FALSE)
length(pca_selection$selected_genes)
#> [1] 17
head(pca_selection$selected_genes)
#> [1] "ENSMUSG00000001506.11" "ENSMUSG00000029661.17" "ENSMUSG00000051747.17"
#> [4] "ENSMUSG00000064351.1"  "ENSMUSG00000119584.1"  "ENSMUSG00000018593.14"
refined <- pca_selection$selected_count_matrix
dim(refined)
#> [1]  8 17

The bundled matrix is already preselected. This step demonstrates how PCA selection works. For your own data, apply it to the full normalized matrix. For example, to select 100 genes from each of four components:

# full_normalized must come from your full normalized matrix, not the reduced example.
full_pca <- pca_analysis(full_normalized, plot_2d = FALSE)
refined_matrix <- feature_selection_pca(full_pca$pca_result, full_normalized,
  num_pcs = 4, num_genes_per_pc = 100)

8 Classify and resample: classification_approach_advanced()

Purpose: draw genes and fit algorithms across all allowed replicate partitions. Input: input. Output: models and tables recording scores, genes, partitions, sample identities and fitting failures.

Parameter How to choose
input_data Table returned by prepare_input_matrix().
algorithms caret methods such as "rf", "ranger" or "svmLinear2"; install their model engines.
hyper_params Named list of algorithm-specific tuning-grid data frames. RF uses mtry; other methods have their own grid columns.
num_resamples Number of gene sets to draw; increases the number of fitted models.
num_genes Genes drawn per set, from the first condition and matched by identity in the others.
train_percentage Fraction of replicates for training; .75 with four replicates gives three training and one test replicate.
metrics Currently only "Accuracy" is supported.
summary_stat "median" or "mean" to summarize partition test scores for each resample.
replace_genes TRUE permits repeated genes, as in the original procedure; FALSE requires enough available genes.
parallel Allows parallel model training; does not automatically configure a worker cluster.
seed Random seed for reproducibility in a compatible recorded environment.
include_gene TRUE preserves gene identity as a predictor in the default procedure. Setting FALSE changes the analysis.
error_handling "stop" reports the failed fit and stops; "continue" records failures and leaves incomplete summaries as NA. 
classification <- classification_approach_advanced(input,
  algorithms = "rf", hyper_params = list(rf = data.frame(mtry = c(1, 3))),
  num_resamples = 3, num_genes = 10, train_percentage = .75,

Where results are stored: eval_table records scores by algorithm, resample and partition; test_eval_table separates held-out replicates; partition_table describes splits; genes_table retains legacy positions; gene_ids_table stores IDs including repeated draws; sample_map identifies samples; status_table records successes/failures; models stores trained models; summary_stat identifies the chosen summary.

Four replicates and .75 training give four partitions. Three resamples and one algorithm produce twelve partition fits, each with its tuning grid. Increase num_resamples to evaluate more gene sets and use num_genes to choose their size. Runtime depends on the data, engine and tuning grid.

mtry is the number of predictors considered at each RF tree split; it is not the number of genes drawn, which is controlled by num_genes. The short c(1, 3) grid is suitable for this small teaching example. For multiple engines, provide a grid for each:

install.packages("ranger")
several_engines <- classification_approach_advanced(input,
  algorithms = c("rf", "ranger"),
  hyper_params = list(
    rf = data.frame(mtry = c(1, 3)),
    ranger = expand.grid(mtry = c(1, 3), splitrule = "gini",
      min.node.size = c(1, 3))),
  num_resamples = 3, num_genes = 10, seed = 123)

Interpretation: training rows represent gene-condition combinations and replicates are predictors. For each held-out replicate, its expression values are repeated into the training-column layout. If several replicates are held out, each is evaluated and their scores are averaged. Internal training retains the original procedure and is not independent validation. Do not present these scores as validated prediction accuracy for unseen patients or unseen genes.

9 Select genes from resamples: genes_from_classification_results()

Purpose: select resamples by explicit IDs or a score threshold and extract their genes. Input: classification tables and refined. Output: selected genes, a filtered matrix and an optional score plot.

Parameter How to choose
eval_table, genes_table Tables returned by classification.
count_matrix Sample-by-gene matrix to filter, here refined.
resamples Explicit IDs, such as c(1, 3); when supplied, these determine selection.
cutoff, metric_column Alternative to IDs: select resamples whose metric is at least the threshold, for example "summary_test_accuracy".
selection_mode "unique" returns the union of genes; "intersect" retains genes present in all selected resamples.
algorithm Restrict selection to an algorithm; NULL uses the union of qualifying IDs across algorithms.
gene_ids_table Explicit ID table; especially useful after CSV export/reimport.
partition_table Identifies partitions in the plot colors.
plot_type "summary" shows summary scores; "all", partition scores; "both", both.
plot_resamples_only TRUE shows selected IDs only; FALSE, all resamples.
return_plot TRUE displays and returns a plot; FALSE only selects genes.
hline_yintercept, hline_color Value and color of the visual reference line; this line does not select genes.
median_color Summary-score color, including when summary_stat = "mean".
test_colors, show_legend Partition colors and legend visibility; provide enough colors for displayed partitions.

For this short example, select the resample with the largest recorded summary. This keeps relationship figures small; it is not a significance test or an independent assessment of discovery performance.

scores <- unique(classification$eval_table[,
  c("algorithm", "resample", "summary_test_accuracy")])

#>   algorithm resample summary_test_accuracy
#> 1        rf        1                 0.550
#> 5        rf        2                 0.550

chosen_id <- scores$resample[which.max(scores$summary_test_accuracy)]
selection <- genes_from_classification_results(classification$eval_table,
  classification$genes_table, refined, resamples = chosen_id,
  gene_ids_table = classification$gene_ids_table,
  partition_table = classification$partition_table, selection_mode = "unique",
  plot_type = "both", plot_resamples_only = FALSE, return_plot = TRUE)

To select resamples by a score threshold and retain genes present in all selected resamples, use:

threshold_selection <- genes_from_classification_results(classification$eval_table,
  classification$genes_table, refined, cutoff = .85,
  metric_column = "summary_test_accuracy", selection_mode = "intersect",
  algorithm = "rf", gene_ids_table = classification$gene_ids_table,
  partition_table = classification$partition_table,
  plot_type = "both", hline_yintercept = .85)

To continue with that choice, assign selected_expression <- threshold_selection$filtered_matrix. No resample may meet the cutoff, or the gene intersection may be empty. Inspect scores and selected sets before proceeding. Do not lower thresholds solely to force a nonempty result. Union/intersection changes the gene universe downstream. CSV loses R attributes: save gene_ids_table explicitly or use RDS to preserve the full classification object and its mapping.

10 Correlate each gene across conditions: acc_analysis()

Purpose: correlate each gene’s two condition-specific replicate vectors. Input: selected_expression, with samples in two ordered blocks. Output: a table if plot = FALSE; a list with results and plot if TRUE.

Parameter How to choose
data Sample-by-gene matrix.
condition_split Endpoints of the two blocks: c(4, 8) means rows 1–4 and 5–8, not just rows 4 and 8.
method "spearman", "pearson" or "kendall"; default Spearman.
plot Also generate a bar plot.
color One color for all bars or two for negative/positive correlations.
orientation "vertical" or "horizontal".
show_legend, rotate_labels Legend visibility and rotated labels on vertical plots.
title, xlab, ylab Plot title and axis labels. 
stopifnot(identical(metadata$Condition,
  rep(c("FLASH", "STANDARD"), each = 4)))
split <- c(4, 8)
acc <- acc_analysis(selected_expression, condition_split = split,
  method = "spearman", plot = TRUE, orientation = "horizontal")

ACC aligns replicates by position: first with first, second with second, and so on. This does not establish biological pairing. The example illustrates an exploratory vector comparison; without justified pairing, do not interpret it as correlation of biologically paired observations. For your own data, arrange and document sample order before calling the function.

11 Correlate genes within each condition: icc_analysis()

Purpose: compute gene-by-gene correlations separately within each condition. Input: the same selected_expression. Output: a list with two correlation matrices used by icc_difference().

Parameter How to choose

Metadata and matrix do not match Exact unique names, metadata row order, and samples removed during filtering.
